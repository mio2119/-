# 赛题分析与建模方案

本记录对应参考提示词“模式 B”第 1 步的赛题解析和第 3 步的建模方案，以题目原文、四份附件和已完成计算为依据。用户当前只要求 LaTeX，覆盖提示词中的 Word、PDF 交付要求；页数和“国奖级”属于目标措辞，不是官方格式依据或获奖保证。本文目标是形成推导清楚、结果可复核且边界明确的论文。

## 一、三小问的输入、未知量、目标与约束

**问题一：一次反射模型。** 输入→空气—外延层—衬底结构、入射角及波数与折射率关系。未知量/决策→几何厚度、界面相移，以及何时可近似忽略色散。目标→由两束复振幅叠加，建立条纹级次差与厚度的关系。约束→只保留表面反射和首次衬底反射；按同一出射波前比较相位，采用局部平行、弱吸收的标量近似。不能预设全部反射相移为零。

**问题二：碳化硅反演。** 输入→附件 1、2，同片晶圆在 10°、15°下的波数—反射率。未知量/决策→共享厚度、分角相移、背景与包络系数，以及色散和拟合窗口。目标→最小化原始光谱残差，给出结果及可靠性。约束→两角同窗、共享厚度；主分析采用 Wang 的 4H 普通光条件色散，限于其适用域。取 2000–3300 cm⁻¹，统一屏蔽 2300–2400 cm⁻¹局部异常；每角保留 2488 点。厚度搜索为 5–10 μm，背景和包络限制为低阶函数。

**问题三：多束识别与修正。** 输入→多次往返结构、附件 3、4 的硅双角光谱及前两问结果。未知量/决策→高阶反射是否有可辨识贡献、硅厚度与有效界面响应、碳化硅是否需要升级模型。目标→推导必要条件与精度影响，比较两束和多束结果。约束→复振幅先求和再取模平方，满足被动衰减；硅使用 450–4000 cm⁻¹窗口、固定参照色散，两种偏振等权平均。比较模型保持相同数据和可比自由度，不把拟合改进当作唯一物理证明。

```text
外延层厚度反演
├─问题一：折射几何 → 界面相移 → 色散相位 → 厚度公式
├─问题二：附件核对 → 双路径初值 → 双角联合拟合 → 可靠性
└─问题三：往返级数 → 必要条件与可见性
           ├─硅：两束截断 ↔ 有效复介电 Airy → 厚度
           └─碳化硅：余弦 ↔ 嵌套 Airy 核 → 是否保留修正
```

## 二、关键陷阱及处理决定

波数 σ 用 cm⁻¹、厚度 d 用 μm，故 λ=10⁴/σ，传播相位为 4π×10⁻⁴dσ√(n²−sin²θ)。不能漏掉 10⁻⁴，也不能直接采用层内斜线路径 2nd/cosβ；同波前有效光程差是 2nd cosβ。局部条纹周期受 n+σn′及反射相位导数控制，原始谱峰还会被背景和包络推移。

近法向强度谱主要约束光学厚度；10°与15°的几何差很小，虽然理想常 n 公式可联立求解，实际 n 与 d 仍强相关。附件缺少独立折射率、晶型、掺杂和温度，文献色散只能作为条件。普通光中红外实测 3–5 μm 与公式总适用域 0.4047–5 μm也需区分。

四表各有7469行，无缺失和重复波数，不套用插补、DBSCAN或特征筛选。共同零值首点不进入主窗口；附件2的262个反射率超过100%的点保留原值，不裁剪峰顶，也不把它们当作真实绝对反射率。物理反射率取0–1，硅观测模型乘100转成百分数；偏置和残差用百分点，增益无量纲。

## 三、基础模型、升级模型及实际选型

基础路线以 FFT 和峰级次定位厚度分支，再用色散两束模型拟合；给定厚度与相移后，变量投影精确求解线性背景和包络。FFT 零填充只细化网格，不增加分辨率。碳化硅主值为7.384314 μm，反射率 RMSE 为0.024400个百分点，建议报告约7.38 μm。

升级路线对碳化硅采用可退化为余弦的有效 Airy 核。升级后厚度7.384155 μm，仅改变−0.000158 μm，而连续块验证 RMSE 从0.032025升至0.033067个百分点，因此保留两束主值。该结论限定于当前透明窗口。

硅采用固定膜层色散、Drude 型有效衬底和有效往返衰减的复振幅 Airy 模型，各角单独线性标定。共同厚度3.405214 μm，建议报告约3.41 μm；与同参数两束截断相比，RMSE由4.36318降至0.67894个百分点，36个留出块中34块改善，支持采用多束模型。有效衰减不能唯一解释成粗糙度、消光系数或相干长度，必要条件也未被附件逐项独立核验。

可靠性同时保留分角结果、窗口变化、折射率单因素扰动及条件分块重采样。两种材料分角厚度差分别为0.04703、0.02772 μm；它们提醒我们，密集采样和较小残差不等于绝对厚度准确。内部验证在已选条纹分支上重新拟合，不能冒充新样本外部验证。当前记录不新增检验或虚构厚度真值，完整公式、系数来源和结果分别见理论、结果章节及《理论与文献.md》。
