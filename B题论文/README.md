# 基于色散校正与多光束比较的外延层厚度反演

这是针对所提供的 **2025 年国赛 B 题**及四份实测光谱完成的研究论文 LaTeX 源码和计算复现材料。论文主文件为 [main.tex](main.tex)。当前只维护源码、数据、结果与图表，未生成 Word 或 PDF。

## 主要计算结果

| 材料 | 条件共同厚度 | 10°独立拟合 | 15°独立拟合 | 主模型 |
| --- | ---: | ---: | ---: | --- |
| 碳化硅 | 7.384314 μm | 7.407811 μm | 7.360780 μm | 文献色散两光束相位模型 |
| 硅 | 3.405214 μm | 3.420549 μm | 3.392831 μm | 含有效衬底响应的多光束模型 |

正文建议以 **约7.38 μm、约3.41 μm** 报告，并附模型条件。这里的“条件”是指假定采用的折射率关系与材料响应模型适用；附件没有独立厚度真值或本晶圆的折射率标定。多位小数用于复现核对，不代表相同位数的绝对测量准确度。

硅两束与多光束模型在相同数据和参数数量下的反射率 RMSE 分别为4.363185、0.678945个百分点；36个留出波数块中34块支持多光束模型。碳化硅有效高阶修正只使厚度改变−0.000158 μm，且五折分块预测变差，因此保留两束模型。

## 一键复现

本次在 Python 3.12.14 下运行；主要依赖版本固定在 `requirements.txt`。在此目录打开终端：

```bash
python -m pip install -r requirements.txt
python run_all.py
```

默认每种材料运行120次移动块残差重抽样。程序从原始工作簿开始重建全部数值结果、图和自动数据表，随后复算逐点预测并检查LaTeX输入文件、图文件、标签和文献键。`results/run_log.json`记录每个阶段的真实运行时间、软件环境和退出码。

已有结果时，可以只重新生成图表并核验：

```bash
python run_all.py --figures-only
```

绘图需要可用的中文字体，程序优先寻找微软雅黑、黑体或Noto Sans CJK SC。当前 Windows 环境已验证图中汉字正常显示。论文编译采用 TeX 发行版自带的 Fandol 与 TeX Gyre 字体，无需上传或安装原模板中的个人字体文件。
